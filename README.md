# Phần 1: Tại sao Nam dùng file Word (.docx) lại bị các bạn chê?
## Sai lầm 1: Đem file Word lên web GitHub để đọc

File Word (.docx) giống như một cục file chứa nhiều thứ bên trong. Khi Nam đẩy lên GitHub, không tự hiện nội dung ra cho mọi người xem mà bắt tải file về máy, rất mất công.

## Sai lầm 2: Làm Git lỗi Conflict

Git quản lý code bằng cách so sánh từng dòng chữ với nhau. Nhưng file Word là dạng nhị phân, nên chỉ cần Nam sửa một dấu phẩy nhỏ, Git tưởng là đổi sạch sẽ cả file và báo lỗi đánh nhau (Conflict)với các bạn khác trong nhóm.
